# SmartFlow Gold Suite · XAUUSD (v4.1)

Paste [`SmartFlow_Gold_Suite.pine`](SmartFlow_Gold_Suite.pine) into the TradingView Pine Editor.

## Chart Mode (start here)

| Mode | Chart shows |
|------|-------------|
| **Clean Chart** | BUY labels + dashboard only (engines still score) |
| **Signal Focus** (default) | AVWAP, POC, nearest FVG (1/side), Sureshot, major rounds, CHoCH |
| **Full Study** | Each engine’s Draw toggle |
| **Custom** | Same — per-engine Draw only |

To get the old crowded chart: set **Full Study**, then enable Draw on E5 OB, E6 LIQ, E4 BOS, E8 FVG, and E9 basic sweeps.

## Engines

E1–E17 stay separate. ▶ ENABLE removes an engine from scoring and drawing.
